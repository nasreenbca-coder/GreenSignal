# 🌱 GreenSignal – Green City

A web-based waste reporting and cleanup coordination platform designed to support cleaner and greener cities.

## 📌 About the Project

GreenSignal allows users to report waste-disposal issues by uploading images and sharing their location. It aims to improve communication between citizens and waste collection teams.

## ✨ Key Features

- 📸 Upload images of waste locations.
- 📍 Location-based waste reporting.
- 🏙️ City-based waste collection coordination.
- 📧 Email notifications.
- 📊 Track waste report status.
- 🏆 Reward system for user participation.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- Python Flask
- SQLite

## ⚙️ Project Purpose

To encourage citizen participation in waste management and support cleaner, more sustainable cities.
